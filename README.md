# 晚霞云海预报（AstrBot 插件）

查询指定城市的晚霞鲜艳度 / 出现概率，以及云浮风车山等点位的云海出现概率。

- 晚霞：SunsetBot GFS/EC + Open-Meteo 五因子
- 云海：Open-Meteo 气压层（山下成云 × 山顶出云）

当前版本：**v1.0.7**

晚霞默认地点：**广东肇庆端州区**（SunsetBot 实际查「肇庆」，不会用会命中朝鲜的「端州」）。云海默认：**云浮风车山**（新兴县水源山 18 号风车）。

## 用链接安装到 AstrBot

```
https://github.com/CGR-MIX/astrbot_plugin_sunset_forecast
```

1. 先在插件管理里 **卸载旧的「晚霞云海预报」**
2. 重启 AstrBot
3. 从 GitHub 安装，粘贴上面的地址（不要填子目录）
4. 装完发 `/晚霞诊断 肇庆`，第一行必须是 `v1.0.7`

AstrBot 的「检查更新」读取 GitHub **Release**，不是每一次 commit。已装过的插件请在配置里把「晚霞默认城市」改成 `广东肇庆端州区`，或卸载后重装。

## 指令

| 指令 | 说明 |
| --- | --- |
| `/晚霞` | 今明两天晚霞（默认广东肇庆端州区） |
| `/晚霞 肇庆` | 指定城市 |
| `/晚霞诊断 肇庆` | 看版本和城市表是否命中 |
| `/火烧云 广州` | 同晚霞 |
| `/云海` | 默认云浮风车山云海 |
| `/晚霞云海 广州` | 广州晚霞 + 默认云海点 |

## 本地命令行

```powershell
python predict.py
python predict.py 肇庆
python predict.py 云浮风车山
```
